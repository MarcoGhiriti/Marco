<original_problem_statement>
The user wants to build a premium mobile application for motorcyclists called **Moto GO**.

**PRODUCT REQUIREMENTS (from initial state + this session):**
-   **Core App Language:** The entire application must be in English.
-   **Routes vs. Events Distinction:**
    -   **Routes:** A path from a start point to an end point, with optional intermediate waypoints. Locations are selected via a Google Maps-like search bar (autocomplete), not manual coordinates. The UI must show pins and a polyline.
    -   **Events:** A single-location gathering for motorcyclists (e.g., meetup, show). The location is selected via a single search bar.
-   **Home Page:**
    -   Should display a list of routes.
    -   **Filtering:** Only show routes that are geographically close to the user's current location.
    -   **Route Cards:** Each route card should be clickable to view details and include a share button.
-   **Route Management:**
    -   **Creation:** A dedicated screen allows users to create routes with a title, description, difficulty, start point, end point, and multiple intermediate waypoints. A start date and time must also be specified.
    -   **Lifecycle:** Routes created by a user should appear on their profile. After a Ride Session for a route is completed, the route itself should be deleted from the database to prevent re-use.
-   **Profile Screen:**
    -   Must include a My Routes section listing all routes created by the user, with a Start Ride button on each.
    -   Clicking the user's level should display a modal or screen showing all available levels and the KM required for each.
-   **Community & Chat:**
    -   **Friend Requests:** Sending a friend request should not automatically add the friend. The recipient must be able to see the request and choose to Accept or Reject it.
    -   **Group Creation:** Users can create groups with a name, description, and a group profile picture (image upload).
    -   **Chat UI:** Both Direct Message (DM) and Group Chat screens should have a dark theme, with a custom background or empty state placeholder featuring a motorcycle icon.
    -   **DM Header:** The header of a DM conversation must show the other user's profile picture and name, and the three-dot menu should be removed.
-   **Gamification & Rankings:**
    -   The Rankings tab should contain a comprehensive list of all available badges in the app, with descriptions on how to unlock them.
-   **Authentication:** JWT-based custom auth (email + password).
</original_problem_statement>
