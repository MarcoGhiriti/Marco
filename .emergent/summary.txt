<original_problem_statement>
The user wants to build a premium mobile application for motorcyclists called **Moto GO**. The work is guided by a detailed Product Requirements Document (PRD).

**PRODUCT REQUIREMENTS (PRD):**

-   **🔔 NOTIFICATIONS HUB:**
    -   A centralized Notifications hub for all alerts: friend requests, route/event/group invitations, and automated reminders.
-   **👥 GROUPS (Control & Clarity):**
    -   Group creators must be able to set a maximum number of members.
    -   Every message bubble in group chat must display the sender's username.
    -   Group creators should be able to edit the group's name and picture.
    -   A search function for public groups.
-   **🧑 PROFILE (Content Management):**
    -   Users must be able to **✏️ Edit** and **🗑️ Delete** their own created routes and events from their profile. The user's 'bio' field should be removed.
-   **🛑 RIDES – ADVANCED FUNCTIONS:**
    -   An active ride session must have a **PAUSE/RESUME** button.
    -   The Active Ride banner should be visible to all participants and show the ride's progress and status (Active/Paused).
    -   The creator should have quick access to Pause/Stop controls.
-   **🗺️ MINI-MAP UX:**
    -   The mini-map preview on route cards must display the main route polyline highlighted, adjacent streets in gray, and text labels for the **start and end city names** directly on the map.
-   **🔗 CONNECTIVITY:**
    -   Functionality should be interconnected. If there's a notification for an invitation, there must be a button in the UI to send that invitation.
